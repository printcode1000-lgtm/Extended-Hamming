# Device Model Documentation

The file `models/65nm_bulk.pm` was downloaded from the University of Minnesota Predictive Technology Model project. The source page identifies it as the conventional 65-nm bulk CMOS model. The file itself states "Beta Version released on 2/22/06" and defines BSIM4 level-54 `nmos` and `pmos` models with nominal temperature 27 C.

PTM supports early design exploration. It is not a commercial foundry PDK, does not establish manufacturability, and supplies no qualified TT/FF/SS corner set in this single file. Consequently, this project does not invent process corners or call the results post-layout or measured silicon data.

Source: https://mec.umn.edu/ptm
