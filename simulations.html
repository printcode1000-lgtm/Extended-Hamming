LTspice 26.0.2 transient simulations compare the architectures under a common University of Minnesota 65-nm predictive bulk-CMOS model. The model is predictive research data, not a commercial foundry PDK.

Traceability chain

Each public result maps from an experiment ID to the circuit netlist, PTM model, generated input waveform, LTspice command, text log, processed CSV/JSON row, and figure. Binary waveform files are intentionally excluded from Git because they are large generated artifacts and can be regenerated.

Reproduce

  1. Clone the repository and install LTspice and Python 3.11 or later.
  2. Run scripts/verify_secded.py and scripts/build_ltspice.py.
  3. Execute scripts/run_ltspice.py --exe "path-to-LTspice.exe" --level ALL.
  4. Run the results pipeline, summary, figure, and web-data scripts.
  5. Compare the generated CSV/JSON, validation status, and charts.
